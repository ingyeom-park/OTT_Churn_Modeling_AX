               2-2. 데이터 연결 흐름  
           View History(MOVIE_NUM) → Movie Master(MOVIE_ID = MOVIE_NUM, TITLE) → Wavve 크롤링(query_title = Movie Master TITLE) 또는 KOBIS(wavve_title = Wavve 크롤링 title) → 장르 등 영화 메타데이터  
     
           Membership(USER_KEY) → User_Mapping(USER_KEY ↔ USER_NUM) → View_History(USER_NUM) → 시청 파생변수  
     
               2-3. 주요 데이터 특성  
                View History의 watch_day 범위: 2021-03-01 ~ 2021-04-05  
                유저당 시청 기간은 최대 21일(3주). 모든 유저 동일 조건이므로 정규화 불필요  
                View History에 시청이력이 있는 유저: 14,967명 (Membership 17,876명 중 약 83%)  
                나머지 약 3,000명은 시청이력 없음. 현재 분석에서는 시청이력 있는 유저만 대상으로 함  
     
               2-4. 이상치 처리  
                비프로모션 집단(promotion_0)에서 gender=N, is_user_verified=0, age=40이 동시에 해당하는 케이스 2,639명(전체의 약 30%) 발견  
                본인인증을 하지 않은 유저의 성별/연령이 기본값으로 채워진 더미 데이터로 판단  
                해당 케이스 분석에서 제거 필요. 제거 후 비프로모션 집단 유효 인원: 약 6,176명  
     
               2-5. 영화 메타데이터 커버리지  
           View History에 등장하는 고유 영화 5,196편 기준:  
                Wavve 크롤링으로 커버: 3,576편  
                KOBIS API로 추가 커버: 999편  
                합산 커버: 4,575편 (약 88%)  
                미커버: 621편 (약 12%) — 판권 만료 등으로 검색 불가한 5년 전 데이터  
     
           두 소스의 장르 체계가 달라 통일 작업 필요. Wavve는 'SF/판타지', '로맨스|드라마' 형태. KOBIS는 '멜로/로맨스', '공포(호러)' 형태.

               4. 현재 문제 상황 및 속앓이  
               4-1. 핵심 문제  
           이탈을 유의미하게 가르는 변수가 사실상 없다. 통계적으로 유의한 것들은 있지만 차이의 크기 자체가 작아서 비즈니스 제언으로 연결하기 어렵다.  
     
                프로모션 여부: 7.2%p 차이. 통계적으론 유의하나 마케팅 전략을 바꿀 만큼 설득력 있는 차이인가에 대한 의문  
                인증 여부: 4.1%p 차이. 더미 이상치 오염으로 신뢰도 낮음  
                View History 시청량 변수: 전체 유의하지 않음  
                유의한 것들(week3, days_to_end): 방향이 역직관적 — 많이 볼수록 오히려 이탈  
     
               4-2. 클러스터링 관련 딜레마  
                클러스터링에 쓸 변별력 있는 변수가 없음. 변수가 약하면 군집이 해석 가능하게 나오기 어려움  
                단일 기준(프로모션 여부)으로 나눈 집단 평균 비교는 7.2%p 차이에 그침  
                세그먼트를 어떤 기준으로 나눠야 프로모션 효과가 더 선명하게 보이는지 미확인  
     
               4-3. 장르 데이터 관련 미완료 작업  
                가설: 특정 장르를 많이 본 유저가 이탈할 확률이 다르다  
                영화 메타데이터(Wavve + KOBIS) 준비 완료. View History 88% 커버 가능  
                두 소스의 장르 체계 통일 필요 (Wavve: SF/판타지, KOBIS: SF + 판타지 분리 등)  
                유저별 장르 비율 파생변수 생성 방식 미결정  
                 편 수 기준 vs 시청시간 기준 — 시청시간 기준이 더 합리적으로 판단됨  
                 복수 장르 영화 처리: 시청시간을 장르 수로 균등 배분하는 방식 채택 예정  
                 합이 1이 되는 비율 방식 vs 절대값(시청시간) 방식 병행 검토 필요  
                장르 변수 생성 후 is_repurchase 유의성 검정이 다음 단계
