세그먼트 score source

churn_risk는 어디서 왔는가?

churn_risk = 1 - repurchase_score입니다. repurchase_score는 15x 단계에서 expanded_no_payment_device 피처셋, overall_with_promotion scope, LightGBM 모델의 OOF(Out-Of-Fold) prediction에서 가져왔습니다.

이 점수는 최종 운영 campaign threshold가 아닙니다. 17x 세그먼트 설계를 위한 diagnostic score이며, 16x SHAP 해석의 payment-removed 기준과 맞추기 위해 선택한 score source입니다.

payment_is_mobile, payment_is_pc, payment_is_android, payment_is_ios는 해석 리스크로 인해 15x에서 제거된 피처입니다. 따라서 세그먼트 배정에는 payment/auth/demographic proxy가 직접 사용되지 않았지만, score model 안에 non-payment proxy caveat feature가 남아 있을 수 있음을 유의해야 합니다.

repurchase_score란?

repurchase_score = P(is_repurchase = 1)

모델이 각 row(구독-이벤트)에 대해 출력하는 재구매 확률 추정값입니다. 0에 가까울수록 재구매 가능성이 낮다고 모델이 본 것이고, 1에 가까울수록 높다고 본 것입니다.

출처: 15x 단계 / expanded_no_payment_device 피처셋 / overall_with_promotion scope / LightGBM OOF prediction

churn_risk란?

churn_risk = 1 − repurchase_score

비즈니스 운용을 위해 재구매 점수를 뒤집은 것입니다. 높을수록 이탈 위험이 크다고 모델이 본 것입니다.

주의: churn_risk가 높다 = repurchase_score가 낮다. 이 둘을 혼동하면 고위험군과 안정군이 완전히 뒤집힙니다.

OOF 점수의 의미

"자기 자신을 학습한 모델이 자신을 채점하지 않는다"는 것이 핵심입니다. 각 row는 자신이 포함되지 않은 fold의 모델로 점수를 받습니다.

주의: 이 OOF 점수는 세그먼트 분류 기준으로 활용됩니다. 최종 campaign threshold 또는 deployment 기준으로 해석하면 안 됩니다.

dataset scope 4종 — 왜 4개로 나눠서 모델을 돌렸나

이 프로젝트의 최상위 분류 축은 is_promotion입니다. 100원딜(프로모션) 구독자와 일반 구독자의 이탈 패턴이 다를 수 있기 때문에, 4가지 scope로 구분해 분석했습니다.

overall_with_promotion ← 점수 출처

전체 row 포함 + is_promotion을 피처로 사용. 프로모션 여부가 재구매 예측에 미치는 영향을 모델이 직접 학습합니다. 이 scope의 LightGBM OOF 점수를 17x 세그먼트 기준으로 사용했습니다.

overall_without_promotion

전체 row 포함이지만 is_promotion을 피처에서 제외. 프로모션 여부를 모르는 상황을 가정한 비교용 scope.

promotion_only

100원딜 구독자(is_promotion=1)만 포함. 이 그룹 내에서 is_promotion은 상수이므로 피처에서 자동 제외.

nonpromotion_only

일반 구독자(is_promotion=0)만 포함. 프로모션 없이 가입한 사람들 안에서의 이탈 패턴.

repurchase_score 분위별 실제 재구매율 — 점수가 의미하는 것

전체 row를 repurchase_score 오름차순으로 정렬해 10등분(decile)했을 때, 각 구간의 실제 재구매율이 얼마인지 보여줍니다. Decile 1 = 모델이 재구매 가능성이 가장 낮다고 본 구간, Decile 10 = 가장 높다고 본 구간.

출처: 15x / expanded_no_payment_device / overall_with_promotion / LightGBM OOF — park.ingyeom/reports/audits/15x_payment_device_sensitivity_260516/15x_calibration_decile_summary.csv

flag_high_risk_top20 = Decile 1 + Decile 2 구간

churn_risk 내림차순으로 상위 20% = repurchase_score 오름차순 하위 20% = Decile 1~2에 해당합니다. 이 두 구간의 실제 재구매율은 20.1%(Decile 1)과 31.8%(Decile 2)로, 전체 평균(71.8%)과 비교하면 현저히 낮습니다.

medium_risk = 대략 Decile 3~5 구간

churn_risk 상위 20~50% = Decile 3~5 구간. 실제 재구매율 50.3%~75.1%. "완전히 위험하진 않지만 주시할 구간"입니다. 세그먼트 4번(medium_risk_retention_decay)이 여기에 포함됩니다.

Decile별 평균 repurchase_score vs 실제 재구매율 비교

모델이 출력한 점수(repurchase_score)와 실제 결과(observed repurchase rate)가 얼마나 일치하는지 확인합니다. 두 선이 가까울수록 점수의 신뢰도가 높습니다.

세그먼트에서 쓰인 핵심 Flag 사전

세그먼트 rule을 이해하려면 flag를 먼저 알아야 합니다. 영어 변수명만 보면 헷갈리므로, 모두 한국어로 풀어 씁니다.

churn_risk

모델 기반 이탈 위험 점수. = 1 - repurchase_score. 높을수록 재구매 안 할 가능성이 크다고 모델이 본 것. 최종 threshold가 아닌 diagnostic score.

계산: 15x OOF LightGBM repurchase_score에서 역산

flag_high_risk_top20

churn_risk 상위 20% 해당 여부. 모델 기반 점수 percentile 기준. "이탈 확정"이 아니라 "모델 점수 상위권"이라는 뜻.

계산: risk_percentile_desc 기준 상위 20% 고정 분위

flag_week3_inactive

3주차(day14~20) 시청 비활성 여부. watch_time_min_w3 또는 watch_session_w3이 0인 경우. 관측창 마지막 주에 거의 안 봤음.

계산: watch_time_min_w3 == 0 AND watch_session_w3 == 0 기준

flag_week3_drop

3주차 시청시간이 2주차보다 감소했는지 여부. 2주차보다 3주차에 식은 경우.

계산: watch_time_min_w3 < watch_time_min_w2 AND diff_between_w3_w2 < 0

flag_retention_decay

3주차 retention이 2주차보다 낮거나 0.5 미만인지. 주차가 갈수록 유지력이 떨어지는 패턴.

계산: retention_w3_ratio < retention_w2_ratio OR retention_w3_ratio < 0.5 고정 임계

flag_only_w1

1주차에만 시청하고 2~3주차에는 거의 시청하지 않은 패턴.

계산: is_only_w1 == 1 (06x 파생 flag)

flag_cold_start_weak

초기 활성화 약화 신호. is_cold_start_3d_fixed 또는 is_cold_start_7d_fixed 중 하나가 1인 경우. 주의: cold_start_3d_fixed는 구독 후 3일 이내 첫 시청 여부(row-level 재계산 fixed 버전).

계산: is_cold_start_3d_fixed == 1 OR is_cold_start_7d_fixed == 1

flag_low_activity

전체 day0~20 시청시간 또는 시청횟수 하위 25% 이하. 총 시청시간 74분 이하 또는 시청횟수 2회 이하.

계산: total_watch_time_min ≤ q25 OR total_watch_count ≤ q25

flag_genre_focused

특정 장르 비중 집중 proxy. max_genre_ratio가 상위 25% 이상. Movie_Master category mapping 기반.

계산: max_genre_ratio ≥ q75

flag_new_movie_oriented

최근 365일 이내 신작 비율 상위 25% 이상. 콘텐츠 proxy.

계산: new_movie_in_365d_ratio ≥ q75

flag_old_movie_oriented

5년 이상 구작 비율 상위 25% 이상. 콘텐츠 proxy.

계산: old_movie_ratio_5y ≥ q75
