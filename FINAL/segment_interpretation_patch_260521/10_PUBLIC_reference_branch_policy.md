> PUBLIC reference branch policy

작성일: 2026-05-21

> 1. 최종 지위

PUBLIC은 final pipeline으로 사용하지 않는다. 최종 기준은 park.ingyeom 파이프라인이며, 이번 FINAL 문서도 park 17x segmentation assignment와 score source를 기준으로 작성한다.

> 2. PUBLIC의 역할

PUBLIC은 100원딜 중심 promo-scope segmentation과 business storyline을 실험한 reference branch다. 이 branch는 헛수고가 아니다. 왜냐하면 100원딜 해석, safe/unsafe wording, demographic action layer, presentation action matrix 구조를 검토하는 우회 검증 역할을 했기 때문이다.

> 3. 직접 가져오지 않는 것

PUBLIC에서 numeric score, segment assignment, final model decision을 직접 가져오지 않는다. PUBLIC 11/12 README는 해당 stage가 emergency reference 또는 model comparison reference이며 final canonical model evidence가 아니라고 기록한다. PUBLIC GB final_result는 promo0/promo1 분리 scope와 log-retention-only input에 기반하므로 park 17x의 row-level LightGBM OOF score source와 섞지 않는다.

> 4. 참고 가능한 것

PUBLIC에서 참고할 수 있는 것은 narrative 구조, visual guide 구성, safe wording, unsafe wording, action matrix의 표현 방식이다. 이 참고는 park 17x 결과를 대체하지 않는다.

> 5. 최종 해석 원칙

최종 기준은 park.ingyeom이다. PUBLIC 산출물은 발표 문장과 시각화 구조 참고용으로만 사용한다. PUBLIC을 canonical으로 승격하지 않는다.
