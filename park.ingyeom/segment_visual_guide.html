17x 세그먼트 시각화 전문 해설서

이 문서는 17x 대표 세그먼트 설계 결과를 비전문가도 오해 없이 이해할 수 있도록 풀어 쓴 해설 HTML입니다. 모든 수치는 실제 17x CSV 산출물 기준이며, 설명은 15x OOF diagnostic score와 day0~20 행동 flag를 결합한 세그먼트 설계 논리에 따라 작성했습니다.

읽기 전 기준

row
단위는 고객이 아님

여기서 말하는 "사람"은 고객 1명이 아니라 subscription-event row 1개입니다. 같은 USER_KEY가 여러 구독 이벤트를 가질 수 있으므로, row count를 고객 수처럼 읽지 마세요.

provisional
임시 설계 라벨

7개 세그먼트명은 고객의 본질적 유형이 아니라 대응 우선순위 설계를 위한 임시 대표 라벨입니다. 최종 고객 유형 확정이 아닙니다.

23,079
총 row 수 (overall_with_promotion 기준)

세그먼트 배정 대상은 23,079개 subscription-event row입니다. 15x OOF diagnostic score와 day0~20 행동 flag를 결합해 7개 대표 라벨 중 하나를 부여합니다.

행동 + 모델
순수 행동 rule이 아님

일부 세그먼트는 모델 기반 churn_risk percentile과 day0~20 행동 flag를 결합합니다. "행동만 봤다"고 설명하면 틀립니다.

1순위부터
우선순위 배정 방식

한 row가 여러 flag를 동시에 만족해도 1순위부터 검사해서 먼저 걸린 세그먼트 하나만 부여합니다. 복수 배정 없음. 응급실 triage와 같은 구조입니다.

인과 아님
가장 중요한 해석 경계

세그먼트 조건에 쓰인 행동 신호가 이탈을 만들었다는 뜻이 아닙니다. 모델이 재구매 여부를 구분할 때 그 신호를 활용했다는 뜻입니다.

세그먼트 score source

churn_risk는 어디서 왔는가?

churn_risk = 1 - repurchase_score입니다. repurchase_score는 15x 단계에서 expanded_no_payment_device 피처셋, overall_with_promotion scope, LightGBM 모델의 OOF(Out-Of-Fold) prediction에서 가져왔습니다.

이 점수는 최종 운영 campaign threshold가 아닙니다. 17x 세그먼트 설계를 위한 diagnostic score이며, 16x SHAP 해석의 payment-removed 기준과 맞추기 위해 선택한 score source입니다.

payment_is_mobile, payment_is_pc, payment_is_android, payment_is_ios는 해석 리스크로 인해 15x에서 제거된 피처입니다. 따라서 세그먼트 배정에는 payment/auth/demographic proxy가 직접 사용되지 않았지만, score model 안에 non-payment proxy caveat feature가 남아 있을 수 있음을 유의해야 합니다.

세그먼트에서 쓰인 핵심 Flag 사전

세그먼트 rule을 이해하려면 flag를 먼저 알아야 합니다. 영어 변수명만 보면 헷갈리므로, 모두 한국어로 풀어 씁니다.

churn_risk

모델 기반 이탈 위험 점수. = 1 - repurchase_score. 높을수록 재구매 안 할 가능성이 크다고 모델이 본 것. 최종 threshold가 아닌 diagnostic score.

계산: 15x OOF LightGBM repurchase_score에서 역산

flag_high_risk_top20

churn_risk 상위 20% 해당 여부. 모델 기반 점수 percentile 기준. "이탈 확정"이 아니라 "모델 점수 상위권"이라는 뜻.

계산: risk_percentile_desc 기준 상위 20% 고정 분위

flag_week3_inactive

3주차(day14~20) 시청 비활성 여부. watch_time_min_w3 또는 watch_session_w3이 0인 경우. 관측창 마지막 주에 거의 안 봤음.

계산: watch_time_min_w3 == 0 AND watch_session_w3 == 0 기준

flag_week3_drop

3주차 시청시간이 2주차보다 감소했는지 여부. 2주차보다 3주차에 식은 경우.

계산: watch_time_min_w3 < watch_time_min_w2 AND diff_between_w3_w2 < 0

flag_retention_decay

3주차 retention이 2주차보다 낮거나 0.5 미만인지. 주차가 갈수록 유지력이 떨어지는 패턴.

계산: retention_w3_ratio < retention_w2_ratio OR retention_w3_ratio < 0.5 고정 임계

flag_only_w1

1주차에만 시청하고 2~3주차에는 거의 시청하지 않은 패턴.

계산: is_only_w1 == 1 (06x 파생 flag)

flag_cold_start_weak

초기 활성화 약화 신호. is_cold_start_3d_fixed 또는 is_cold_start_7d_fixed 중 하나가 1인 경우. 주의: cold_start_3d_fixed는 구독 후 3일 이내 첫 시청 여부(row-level 재계산 fixed 버전).

계산: is_cold_start_3d_fixed == 1 OR is_cold_start_7d_fixed == 1

flag_low_activity

전체 day0~20 시청시간 또는 시청횟수 하위 25% 이하. 총 시청시간 74분 이하 또는 시청횟수 2회 이하.

계산: total_watch_time_min ≤ q25 OR total_watch_count ≤ q25

flag_genre_focused

특정 장르 비중 집중 proxy. max_genre_ratio가 상위 25% 이상. Movie_Master category mapping 기반.

계산: max_genre_ratio ≥ q75

flag_new_movie_oriented

최근 365일 이내 신작 비율 상위 25% 이상. 콘텐츠 proxy.

계산: new_movie_in_365d_ratio ≥ q75

flag_old_movie_oriented

5년 이상 구작 비율 상위 25% 이상. 콘텐츠 proxy.

계산: old_movie_ratio_5y ≥ q75

flag_low_risk_stable

모델 위험도 하위 20% 구간이고 3주차 retention이 안정적인 경우. "위험도 낮고 시청 유지도 안정".

계산: risk_percentile_desc (하위 20%) AND retention_w3_ratio 안정 기준 충족

안전한 표현

"저희는 먼저 day21 시점의 재구매 위험점수(churn_risk)를 만들고, day0~20 관측창 안에서 나타난 행동 flag를 결합했습니다."

"고위험군은 점수가 높으면서 3주차 비활성, 3주차 감소, retention decay, only W1, 저활동 같은 구체적 행동 패턴이 함께 나타나는 경우로 나누었습니다."

"한 row가 여러 조건을 동시에 만족할 수 있기 때문에, 1~7순위 우선순위로 하나의 대표 세그먼트만 부여했습니다."

"이 세그먼트는 최종 고객 유형이 아니라 provisional 대응 후보입니다."

"3주차에 안 봐서 이탈했다." → 인과 주장. SHAP은 모델 설명이지 원인이 아닙니다.

"이 3,793명은 고위험 고객이다." → row는 고객이 아니라 subscription-event row입니다.

"최종 채택 모델이다." → 14x/15x는 diagnostic score이며 final model selection이 아닙니다.

"iOS 결제 고객은 충성도가 높으니 업셀한다." → payment/auth/demographic proxy 직접 타기팅은 해석 리스크가 있습니다.

"이 사람은 로맨스를 좋아한다." → proxy이므로 단정 금지.
