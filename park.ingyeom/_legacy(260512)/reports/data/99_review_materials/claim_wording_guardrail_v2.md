# Claim Wording Guardrail — OTT Churn Prediction v2

> 이 문서는 발표, 보고서, 구두 설명에서 사용할 수 있는 표현과 사용해서는 안 되는 표현을 정리합니다.
> 모든 수치는 Stage 02b forensic audit 완료 전까지 PROVISIONAL입니다.

---

## 원칙 요약

| 원칙 | 설명 |
|---|---|
| 인과 금지 | 모델은 상관관계를 학습합니다. 인과관계를 주장하지 않습니다. |
| SHAP ≠ 원인 | SHAP은 예측 기여도이며 인과 효과가 아닙니다. |
| 수치 한정 | 확정되지 않은 수치는 PLACEHOLDER로 표기하거나 "약 ~" 수준으로만 언급합니다. |
| 윈도우 명시 | 모든 성능 수치에 w1_3 또는 w1_4를 반드시 명시합니다. |
| Provisional 표시 | 02b 완료 전 모든 downstream 결과는 provisional임을 명시합니다. |

## 금지 표현 목록

### Category A: 인과관계 주장

| 금지 표현 | 위험한 이유 | 안전한 대체 표현 |
|---|---|---|
| "X가 이탈을 유발했다" | 인과관계를 단정함. 교란변수 무시. | "X는 이탈 예측 모델에서 높은 관련성을 보였다" |
| "X를 개선하면 이탈이 줄어든다" | 개입 효과를 보장하는 표현. RCT 없이 불가능. | "X가 낮은 집단에서 이탈률이 관찰상 더 높았다" |
| "X 때문에 이탈한다" | 단일 원인 귀속. 현실은 복합적. | "X와 이탈 간에 통계적 연관이 있다" |
| "X를 늘리면 잔존율이 오른다" | 미검증 개입 효과 주장. | "X가 높은 사용자 집단에서 잔존율이 더 높게 관찰되었다" |

### Category B: SHAP 과잉해석

| 금지 표현 | 위험한 이유 | 안전한 대체 표현 |
|---|---|---|
| "SHAP이 높으니 이 피처가 핵심 원인이다" | SHAP은 모델 기여도이지 원인이 아님. | "이 피처는 모델 예측에서 가장 높은 기여도를 보였다" |
| "SHAP 분석으로 이탈 원인을 파악했다" | 인과 분석이 아닌 예측 기여도 분석임. | "SHAP 분석으로 예측에 가장 영향력 있는 피처를 식별했다" |
| "모델이 이탈 원인을 설명한다" | 모델은 패턴을 학습하며, 원인을 설명하지 않음. | "모델은 이탈 가능성이 높은 패턴을 학습했다" |

### Category C: 성능 수치 과장

| 금지 표현 | 위험한 이유 | 안전한 대체 표현 |
|---|---|---|
| "AUC 0.90 달성" (확정 표현) | 02b 이후 수치 변동 가능. w1_4는 낙관적 상한. | "현재 preliminary 결과에서 w1_4 기준 AUC [PLACEHOLDER]로 관찰됨 (02b 이후 확정)" |
| "모델 정확도 XX%" | AUC와 accuracy는 다른 지표. 임계값에 따라 달라짐. | "ROC AUC [PLACEHOLDER] (임계값 0.5 기준 precision/recall은 별도 확인)" |
| "최고 성능 모델" (무조건) | 어떤 기준인지, 어떤 윈도우인지 맥락 필요. | "w1_4 / membership+usage+content 피처셋 / LightGBM 기준 preliminary AUC [PLACEHOLDER]" |
| "정확하게 예측한다" | 확률 모델은 정확도 보장 불가. | "예측 확률을 제공하며, 고위험군 식별에 활용 가능하다" |

### Category D: 일반화 과잉

| 금지 표현 | 위험한 이유 | 안전한 대체 표현 |
|---|---|---|
| "이 모델을 배포하면 이탈을 막을 수 있다" | 배포 효과와 모델 성능은 별개. | "이 모델은 이탈 위험군을 식별하는 데 활용될 수 있다" |
| "모든 OTT 서비스에 적용 가능하다" | 특정 서비스 데이터로 학습된 모델. | "이 서비스의 특성을 반영하여 학습되었으며, 다른 서비스 적용 시 재검증이 필요하다" |
| "미래 이탈도 동일하게 예측된다" | 시간적 분포 변화(covariate shift) 무시. | "동일 기간 hold-out 기준 성능이며, 미래 코호트 성능은 별도 검증이 필요하다" |

### Category E: 수치 미명시

| 금지 표현 | 위험한 이유 | 안전한 대체 표현 |
|---|---|---|
| "높은 AUC를 기록했다" | 어느 모델인지, 어느 윈도우인지 불명확. | "w1_3 / HistGradientBoosting 기준 preliminary AUC [PLACEHOLDER]" |
| "이탈 예측이 잘 된다" | 정량 근거 없는 주관적 표현. | "ROC AUC 기준 [PLACEHOLDER]로, 무작위 예측 대비 유의미한 차이가 있다" |
| "대부분의 이탈자를 잡아낸다" | recall 수치 없이 불가능한 주장. | "임계값 X 기준, recall [PLACEHOLDER], precision [PLACEHOLDER]" |
