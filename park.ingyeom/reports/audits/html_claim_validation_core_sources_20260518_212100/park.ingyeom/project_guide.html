100원딜 OTT 이탈 분석 — 프로젝트 해설서

이 문서는 프로젝트를 처음 보는 사람도 구조를 완전히 이해할 수 있도록 만든 설명형 가이드입니다.

⚠️ 이 문서를 읽기 전 반드시 알아야 할 5가지

① row ≠ 고객
분석 단위는 subscription-event row입니다. USER_KEY에 중복이 있어(143명 = 352 rows) 이 문서의 모든 수치는 행(row) 수이지 고객 수가 아닙니다. "고객 3,793명이 이탈 위험"이라고 읽으면 안 됩니다.
② 100원딜 ≠ 인과
100원딜 여부(is_promotion)는 코호트 분리 기준이자 모델 피처이지만, 이탈의 원인이라고 해석할 수 없습니다. 관찰된 상관관계일 뿐이며 A/B 실험 없이 인과를 주장해서는 안 됩니다.
③ segment = provisional
7개 세그먼트는 모두 임시 설계(provisional)입니다. 최종 고객 유형이 아니며, 비즈니스 운영에 바로 적용하기 전 검증이 필요합니다. "이 고객은 이탈한다"는 단정은 금지입니다.
④ SHAP ≠ 인과
SHAP 수치는 "모델이 재구매 여부를 구분할 때 해당 피처를 얼마나 활용했는가"를 보여줍니다. watch_time_w3가 높다고 해서 "시청 시간이 재구매를 일으킨다"는 해석은 틀립니다.
⑤ day21 이후 데이터 = 피처 금지
모든 피처는 day0~20 관측창 내 데이터만 사용합니다. day21 이후는 대응 기간이므로 해당 구간의 행동 데이터를 피처로 쓰면 데이터 누수(leakage)가 발생합니다. "4주차까지 보고 판단했다"는 서술은 오류입니다.
