먼저 질문 하나: 이 단어는 어느 쪽 증거인가?

스팸 메일을 하나 분류한다고 해보겠습니다. 메일 안에 free, winner, meeting 같은 단어가 들어 있습니다. 나이브 베이즈는 이 단어들을 한꺼번에 복잡하게 묶어 보지 않고, 하나씩 떼어 놓고 “이 단어는 과거에 어느 클래스에서 더 자주 나왔나?”를 봅니다.

여기서 나이브라는 말 때문에 모델이 허술하다는 느낌을 받을 수 있습니다. 그런데 이 말은 모델이 멍청하다는 뜻이라기보다, 특성들 사이의 복잡한 관계를 일단 과감하게 단순화한다는 뜻에 가깝습니다. 다시 말해, 단어들이 서로 어떤 조합으로 등장했는지까지 깊게 파고들기보다는, 단어 하나하나의 증거력을 따로 계산하는 방식입니다.

예를 들어 free라는 단어가 스팸 메일에서 훨씬 자주 나왔다면, 이 단어는 스팸 쪽 증거가 됩니다. 반대로 meeting이나 project 같은 단어가 정상 메일에서 자주 나왔다면, 이 단어들은 정상 메일 쪽 증거가 됩니다. 이 증거들이 하나씩 점수판에 쌓이고, 마지막에 어느 쪽 점수가 더 높은지를 보는 식입니다.

탐정으로 비유하면, 나이브 베이즈는 사건 현장의 모든 단서가 서로 어떤 관계를 맺는지까지 정교하게 추적하는 탐정은 아닙니다. 대신 단서 하나하나를 보면서 “이 단서는 과거에 어떤 사건에서 많이 나왔지?”를 빠르게 세는 탐정에 가깝습니다. 그래서 아주 정교한 모델보다 성능이 낮을 수는 있지만, 대신 학습이 빠르고 설명하기 쉽다는 장점이 생깁니다.

여기서 잡고 갈 포인트는 하나입니다. 훈련 단계에서는 클래스별 통계를 모으고, 예측 단계에서는 새 데이터가 어느 클래스의 통계와 더 잘 맞는지 비교합니다. 나이브 베이즈는 복잡한 관계망을 그리는 모델이 아니라, 각 특성을 증거처럼 쌓아 올려 빠르게 판단하는 모델입니다.
Interactive demo · 증거가 쌓이는 점수판

단어를 눌러보면, 선택된 단어들이 Spam과 Ham 점수판에 어떻게 쌓이는지 볼 수 있습니다.

선택된 단어가 없습니다.

실제 모델은 로그 확률과 smoothing을 사용합니다. 여기서는 “특성별 증거가 클래스 점수로 쌓인다”는 직관을 먼저 잡기 위한 단순화된 화면입니다.

관찰 포인트

  • 각 단어는 독립적인 증거처럼 점수에 기여합니다.
  • 스팸 쪽에서 자주 보인 단어를 누르면 Spam 점수가 올라갑니다.
  • 정상 메일 쪽에서 자주 보인 단어를 누르면 Ham 점수가 올라갑니다.
  • 중요한 건 복잡한 조합이 아니라, 클래스별 단순 통계가 점수로 쌓인다는 구조입니다.

점수판 읽는 법

단어 하나하나가 Spam과 Ham 점수판에 따로 올라갑니다. 이 화면에서는 모든 단어의 조합을 복잡하게 해석하기보다, 각 단어가 어느 클래스에서 더 자주 나왔는지를 모아 최종 판단한다는 흐름을 보면 됩니다.

02 / 06

세 가지 나이브 베이즈: 데이터 모양이 다르면 모델도 달라진다

이제 모델 이름을 세 개로 나눠보겠습니다. scikit-learn에는 GaussianNB, BernoulliNB, MultinomialNB가 있습니다. 이름은 비슷하지만, 핵심 차이는 “이 특성을 어떤 종류의 숫자로 볼 것인가?”에 있습니다.

연속적인 측정값이면 GaussianNB가 자연스럽고, 0과 1처럼 등장 여부만 보면 BernoulliNB가 맞습니다. 단어가 몇 번 나왔는지처럼 개수를 세는 데이터라면 MultinomialNB가 더 잘 맞습니다. 결국 모델 선택은 멋있어 보이는 이름을 고르는 문제가 아니라, 내 데이터의 모양을 먼저 확인하는 문제입니다.

그래서 이 부분은 수식보다 질문이 먼저입니다. “내 특성은 연속값인가, 등장 여부인가, 아니면 카운트인가?” 이 질문에 답하면 세 모델의 구분이 훨씬 쉬워집니다.

GaussianNB(가우시안 나이브베이즈)

연속값 특성

길이, 무게, 점수, 농도처럼 연속적으로 변하는 숫자를 다룹니다. 클래스마다 평균과 표준편차를 저장해 두고, 새 값이 어느 클래스의 분포에서 더 그럴듯한지 봅니다.

BernoulliNB(베르누이 나이브베이즈)

0/1 이진 특성

값이 0 또는 1인 상황에 잘 맞습니다. 텍스트에서는 “이 단어가 등장했는가, 등장하지 않았는가?”만 보는 방식으로 이해하면 됩니다.

MultinomialNB(다항분포 나이브베이즈)

카운트 특성

단어 등장 횟수처럼 카운트 데이터에 잘 맞습니다. “등장했는가?”에서 한 걸음 더 나아가 “몇 번 등장했는가?”까지 반영합니다.

정리: BernoulliNB와 MultinomialNB는 텍스트 데이터에서 자주 등장합니다. 텍스트는 단어 종류는 많은데, 한 문서 안에서는 대부분의 단어가 0인 희소한 형태가 되기 쉽기 때문입니다. 이럴 때 나이브 베이즈의 빠른 학습과 예측이 꽤 강한 기준점이 됩니다.

용어를 잠깐 정리하고 가겠습니다.

가우시안 분포(Gaussian Distribution): 평균을 중심으로 좌우 대칭인 종 모양의 연속 확률 분포입니다. 흔히 말하는 정규분포와 같은 의미로 보면 됩니다.

베르누이 분포(Bernoulli Distribution): 한 번의 시행 결과가 성공(1) 또는 실패(0)처럼 두 가지로만 나뉘는 이산 확률 분포입니다.

다항 분포(Multinomial Distribution): 베르누이 분포를 여러 범주로 확장한 형태입니다. 예를 들어 주사위를 여러 번 던졌을 때 1이 몇 번, 2가 몇 번, 3이 몇 번 나왔는지를 함께 세는 상황을 생각하면 됩니다.

03 / 06

BernoulliNB: 일단 나왔는지, 안 나왔는지만 본다

BernoulliNB는 특성의 크기보다 등장 여부를 봅니다. 값이 1이면 나타난 것이고, 0이면 나타나지 않은 것입니다. 그러면 모델은 클래스별로 각 특성이 몇 번 1로 등장했는지를 세면서 통계를 만듭니다.

아래 표에서 행은 데이터 포인트이고, 열은 네 개의 이진 특성입니다. 셀을 눌러 0과 1을 바꿔보면 오른쪽 막대도 같이 바뀝니다. 여기서 봐야 할 건 예측 경계가 아닙니다. 먼저 클래스 0끼리 모아 세고, 클래스 1끼리 모아 세는 방식 자체입니다.

Interactive demo · 교재 예제 행렬 바꿔보기

초록색 1은 해당 특성이 등장했다는 뜻입니다. 막대는 클래스별로 각 feature가 몇 번 등장했는지를 보여줍니다.

이 예제에서 봐야 할 것

이 작은 행렬은 BernoulliNB가 통계를 어떻게 모으는지 보여주는 예제입니다. 클래스 0인 행들만 따로 모아 각 열의 1을 세고, 클래스 1에 대해서도 같은 일을 합니다.

무엇을 관찰할 것인가

  • 클래스 0의 행을 바꾸면 파란 막대가 바뀝니다.
  • 클래스 1의 행을 바꾸면 빨간 막대가 바뀝니다.
  • 새 데이터가 들어오면 이 카운트 패턴과 비교해서 어느 클래스 쪽 증거가 더 강한지 보게 됩니다.
import numpy as np

X = np.array([[0, 1, 0, 1],
              [1, 0, 1, 1],
              [0, 0, 0, 1],
              [1, 0, 1, 0]])
y = np.array([0, 1, 0, 1])

counts = {}
for label in np.unique(y):
    counts[label] = X[y == label].sum(axis=0)
04 / 06

MultinomialNB: 단어가 몇 번 나왔는지까지 본다

이제 질문이 조금 바뀝니다. BernoulliNB가 “이 단어가 나왔나?”를 물었다면, MultinomialNB는 “몇 번 나왔나?”까지 봅니다. 텍스트 분류에서는 각 단어의 등장 횟수가 그대로 특성이 될 수 있기 때문에 이 모델이 자연스럽게 연결됩니다.

예를 들어 메일에 winner가 한 번 나온 경우와, winner, free, prize가 여러 번 반복되는 경우를 같다고 보기는 어렵습니다. 등장 여부만 보면 둘 다 “나왔다”로 끝나지만, 카운트를 보면 증거의 강도가 달라집니다. MultinomialNB는 바로 이 차이를 반영합니다.

alpha는 모든 특성에 작은 가상의 카운트를 더해 통계를 부드럽게 만드는 값입니다. 특정 단어가 우연히 한 번도 안 나왔다고 해서 확률이 극단적으로 0에 가까워지는 상황을 완화합니다.

관찰 포인트

  • 같은 단어를 여러 번 누르면 해당 단어의 카운트가 증가합니다.
  • 카운트가 커질수록 그 단어가 자주 등장한 클래스 쪽 점수가 더 강해집니다.
  • alpha가 커지면 클래스별 차이가 조금 완만해지고, 극단적인 판단이 줄어듭니다.
05 / 06

GaussianNB: 연속값은 평균과 표준편차로 본다

이번에는 텍스트가 아니라 연속적인 숫자라고 생각해보겠습니다. 키, 길이, 점수, 농도처럼 값이 쭉 이어지는 데이터라면 0/1이나 카운트로 보는 방식이 어색합니다. 이럴 때 GaussianNB는 클래스마다 각 특성의 평균과 표준편차를 저장합니다.

직관적으로는 각 클래스가 자기만의 종 모양 분포를 가지고 있다고 보면 됩니다. 새 값이 들어오면 “이 값은 어느 클래스의 분포에서 더 그럴듯한가?”를 비교합니다. 아래 그래프에서는 초록색 세로선이 새 데이터이고, 그 위치에서 더 높은 곡선을 가진 클래스가 더 그럴듯한 후보가 됩니다.

그래프를 어떻게 읽을 것인가

파란 곡선은 Class 0, 빨간 곡선은 Class 1의 분포입니다. 초록 세로선을 움직여보면, 같은 값이라도 어느 분포에 가까운지에 따라 예측 후보가 바뀝니다.

여기서의 포인트

GaussianNB의 핵심은 연속값을 클래스별 분포로 본다는 점입니다. 수식보다 먼저 “각 클래스마다 평균과 표준편차를 저장해 두고 새 값을 비교한다”는 구조를 잡으면 됩니다.

06 / 06

alpha와 장단점: 빠르지만, 단순화의 대가도 있다

마지막으로 alpha를 보겠습니다. BernoulliNB와 MultinomialNB에서 alpha는 통계를 조금 부드럽게 만드는 값입니다. 쉽게 말하면, 실제 데이터에만 너무 딱 달라붙지 않도록 작은 완충재를 넣는 역할을 합니다.

어떤 단어가 특정 클래스에서 한 번도 등장하지 않았다고 해보겠습니다. 그러면 모델이 “이 단어가 나오면 이 클래스일 가능성은 거의 없다”처럼 너무 극단적으로 반응할 수 있습니다. alpha는 여기에 작은 가상의 카운트를 더해서, 통계가 한쪽으로 과하게 굳는 것을 막아줍니다. alpha가 크면 더 부드러워지고, alpha가 작으면 실제 훈련 데이터의 카운트가 더 직접적으로 반영됩니다.

실제 학습 전체를 재현한 화면은 아닙니다. 여기서는 alpha가 0이었던 카운트에도 작은 값을 더해 통계를 덜 극단적으로 만든다는 느낌을 보여줍니다.

강점

  • 학습과 예측이 매우 빠릅니다.
  • 훈련 절차가 비교적 단순해서 설명하기 쉽습니다.
  • 단어 수가 많은 고차원 희소 데이터에서 좋은 기준 모델이 됩니다.
  • 큰 데이터셋에서 처음 비교할 baseline으로 쓰기 좋습니다.

약점

  • 특성 사이의 복잡한 상호작용은 잘 잡지 못합니다.
  • 데이터 구조가 복잡하면 선형 모델이나 다른 모델보다 성능이 낮을 수 있습니다.
  • coef_가 선형 모델의 가중치와 같은 의미는 아니므로 해석할 때 조심해야 합니다.
from sklearn.model_selection import train_test_split
