핵심 질문: 각 증거가 어느 클래스 쪽을 더 가리키는가?

나이브 베이즈 분류기는 선형 모델과 비슷한 형태의 빠른 분류기입니다. 교재는 이 모델들이 각 특성을 개별적으로 살펴보고, 클래스마다 단순한 통계를 수집하기 때문에 학습이 매우 빠르다고 설명합니다.

본래 "나이브"라는 단어는 (경험·지식 부족 등으로) 순진해 빠진, (모자랄 정도로) 순진한 이라는 뜻이지만, 여기서의 “나이브”는 모델이 어리석다는 뜻이 아닙니다. 오히려 복잡한 관계를 모두 추적하지 않고, 특성들을 상당히 단순하게 다룬다는 뜻에 가깝습니다.

예를 들어 이메일을 분류할 때 “free”라는 단어, “meeting”이라는 단어, “winner”라는 단어를 각각 하나의 증거처럼 보고, 이 증거들이 스팸 쪽에 더 자주 나타났는지 정상 메일 쪽에 더 자주 나타났는지를 따로따로 모으는 것입니다.

사건 현장의 탐정으로 비유를 하자면, 나이브 베이즈는 현장의 모든 증거들 사이의 복잡한 상호작용을 분석하는 방식이 아닙니다. 대신 증거 하나하나에 대해 “이 증거는 과거에 어느 사건 유형에서 더 자주 보였나?”를 빠르게 세어보는 식입니다. 그래서 정교한 모델보다 성능이 약간 낮을 수 있지만, 대신 엄청나게 빠르고 이해하기 쉽습니다.

핵심 흐름은 단순합니다. 훈련 단계에서는 클래스별 통계를 모으고, 예측 단계에서는 새 데이터가 각 클래스의 통계와 얼마나 잘 맞는지 비교합니다. 정리하자면, 모든 특성의 관계망을 정교하게 그리는 모델이 아닌, 각 특성을 따로 보고 클래스마다 얼마나 자주 나타나는지 같은 단순한 통계를 모아 빠르게 판단하는 방식!

관찰 포인트

  • 각 단어는 독립적인 증거처럼 점수에 기여합니다.
  • 스팸 쪽 단어가 많으면 Spam 점수가 올라갑니다.
  • 업무 메일 쪽 단어가 많으면 Ham 점수가 올라갑니다.
  • 복잡한 상호작용보다 클래스별 단순 통계가 중심입니다.

발표 멘트

“나이브 베이즈는 모든 특성의 관계망을 정교하게 그리는 모델이 아닙니다. 각 특성을 따로 보고, 클래스마다 얼마나 자주 나타나는지 같은 단순한 통계를 모아 빠르게 판단합니다.”

scikit-learn의 세 가지 나이브 베이즈

교재는 scikit-learn에 구현된 나이브 베이즈 분류기를 GaussianNB(가우시안), BernoulliNB(베르누이), MultinomialNB(다항분포) 세 가지로 정리합니다. 차이는 “각 특성을 어떤 종류의 데이터로 볼 것인가”에 있습니다.

이 세 모델은 같은 이름 아래 묶이지만, 바라보는 데이터의 모양이 다릅니다. 가우시안은 연속적인 측정값을 다루고, 베르누이는 0/1처럼 켜짐과 꺼짐만 있는 특성을 다루며, 다항 분포은 단어가 몇 번 등장했는지처럼 카운트 데이터를 다룹니다.

따라서 나이브 베이즈를 처음 배울 때는 수식보다 먼저 “내 특성의 의미가 무엇인가?”를 묻는 것이 좋습니다. 특성이 연속값인지, 이진값인지, 개수인지에 따라 선택하는 모델이 달라집니다.

GaussianNB(가우시안 나이브베이즈)

연속값 특성

각 클래스에서 특성의 평균과 표준편차를 저장합니다. 예를 들어 측정값, 길이, 무게, 농도처럼 연속적인 숫자 특성에 적용할 수 있습니다.

BernoulliNB(베르누이 나이브베이즈)

0/1 이진 특성

각 특성이 0이 아닌 경우가 클래스별로 얼마나 자주 나타나는지 셉니다. 단어가 등장했는지 여부만 보는 텍스트 표현에 사용할 수 있습니다.

MultinomialNB(다항분포 나이브베이즈)

카운트 특성

특성값의 평균적인 크기를 클래스별로 고려합니다. 단어가 몇 번 등장했는지 세는 문서 분류에서 널리 사용됩니다.

정리: BernoulliNB와 MultinomialNB는 텍스트 데이터 분류에서 자주 사용됩니다. 특히 텍스트는 단어 수가 많고 대부분의 문서에서 대부분의 단어가 등장하지 않는 희소한 형태가 되기 때문에, 나이브 베이즈의 빠른 학습과 예측이 강점으로 작동합니다.

내가 잘 모르겠어서 붙이는 설명!

가우시안 분포(Gaussian Distribution):평균을 중심으로 좌우 대칭인 종 모양을 가진 연속 확률 분포, 정규분포(Normal Distribution)와 같은 의미

베르누이 분포(Bernoulli Distribution): 1회 시행에서 결과가 '성공(1)' 또는 '실패(0)'로만 나뉘는 이산확률분포.

다항 분포(Multinomial Distribution): 베르누이 분포의 확장, 결과가 세 가지 이상인 시행으로 확장한 것.
예를 들어 주사위는 결과가 1~6까지 여섯 가지. 이 주사위를 10번 던졌을 때 1이 몇 번, 2가 몇 번, ... 6이 몇 번 나올지의 확률 분포가 다항 분포이다.

BernoulliNB: 0이 아닌 특성을 클래스별로 센다

BernoulliNB는 각 특성이 나타났는가(1), 나타나지 않았는가(0)를 봅니다. 이진 특성 행렬이 주어지면, 클래스마다 각 특성이 몇 번 1로 나타났는지 세는 방식으로 통계를 만듭니다.

아래 표는 교재의 작은 예제를 시각화한 것입니다.
행은 데이터 포인트이고, 열은 네 개의 이진 특성입니다. 셀을 클릭하면 0과 1이 바뀌고, 오른쪽 통계가 즉시 갱신됩니다.
여기서 봐야 할 것은 모델이 복잡한 경계를 먼저 만드는 것이 아니라, 클래스별로 단순한 카운트를 모은다는 점입니다.

Interactive demo · 교재 예제 행렬 바꿔보기

초록색 1은 해당 특성이 “0이 아님”을 뜻합니다. 막대는 클래스별 feature count입니다.

교재 예제의 핵심

교재는 네 개의 데이터 포인트와 네 개의 이진 특성으로 BernoulliNB의 카운팅 방식을 설명합니다.클래스 0에 속한 행들만 모아 각 열의 1을 세고, 클래스 1에 대해서도 같은 작업을 합니다.

무엇을 관찰할 것인가

  • 클래스 0의 행을 바꾸면 파란 막대가 변합니다.
  • 클래스 1의 행을 바꾸면 빨간 막대가 변합니다.
  • 예측은 새 데이터가 어느 클래스의 카운트 패턴과 더 잘 맞는지 비교하는 방향으로 이루어집니다.
import numpy as np

X = np.array([[0, 1, 0, 1],
              [1, 0, 1, 1],
              [0, 0, 0, 1],
              [1, 0, 1, 0]])
y = np.array([0, 1, 0, 1])

counts = {}
for label in np.unique(y):
    counts[label] = X[y == label].sum(axis=0)

MultinomialNB: 단어가 몇 번 등장했는지를 본다

MultinomialNB는 특성값이 count일 때 잘 맞습니다.
텍스트 분류에서는 각 단어가 문서 안에 몇 번 등장했는지가 특성이 될 수 있으므로, 이 모델이 특히 자연스럽게 연결됩니다. 위에서 보았던 스팸인가 아닌가의 분류기가 예시로 쓰일 수 있습니다.

BernoulliNB가 “단어가 등장했는가?”를 묻는다면, MultinomialNB는 “단어가 몇 번 등장했는가?”를 묻습니다.
짧은 메일에 “winner”가 한 번 나온 것과, 긴 메일에서 “winner, free, prize”가 반복해서 나온 것은 증거의 강도가 같을 수 없습니다.
텍스트 분류에서 문서는 거대한 단어 카운트 벡터가 됩니다. 대부분의 단어는 0이고 일부 단어만 양수입니다. 나이브 베이즈는 이런 희소 카운트 데이터에서 매우 빠르게 작동합니다.

alpha smoothing 1.0

alpha는 교재의 설명처럼 모든 특성에 양의 값을 가진 가상 데이터 포인트를 더해 통계를 부드럽게 만드는 효과로 생각할 수 있습니다.

관찰 포인트

  • 같은 단어를 여러 번 누르면 해당 단어의 카운트가 증가합니다.
  • 카운트가 커질수록 그 단어가 자주 나타나는 클래스 쪽 점수가 강해집니다.
  • alpha가 커지면 클래스별 통계가 더 부드러워져 극단적인 차이가 줄어듭니다.

GaussianNB: 평균과 표준편차로 연속값을 본다

GaussianNB는 연속적인 숫자 특성에 사용할 수 있습니다. 위에서 우리는 가우시안 분포가 정규분포와 비슷한 형태를 띈다고 언급했습니다. 교재는 GaussianNB가 클래스별로 각 특성의 평균과 표준편차를 저장한다고 설명합니다.

이 모델을 직관적으로 보면, 각 클래스가 자기만의 종 모양 분포를 가지고 있다고 생각할 수 있습니다. 새 값이 들어오면 “이 값은 어느 클래스의 분포에서 더 그럴듯한가?”를 비교합니다. 아래 시각화는 하나의 특성만 있는 상황을 단순화해 보여줍니다.

어떻게 읽을 것인가

파란 곡선은 Class 0의 연속값 분포, 빨간 곡선은 Class 1의 분포를 나타냅니다. 초록 세로선이 새 데이터입니다. 세로선 위치에서 더 높은 곡선을 가진 클래스가 더 그럴듯한 후보가 됩니다.

포인트

GaussianNB는 모든 연속 데이터에 적용할 수 있습니다. 하지만, 교재는 세부 수식보다 “각 클래스마다 평균과 표준편차를 저장한다”는 통계 관점을 강조하고 있습니다.

alpha, 강점, 약점: 빠른 기준 모델로서의 가치

교재는 MultinomialNB와 BernoulliNB의 주요 파라미터로 alpha를 언급합니다.
alpha는 모델 복잡도를 조절하며, 통계를 일부 다듬는 smoothing하는 역할을 합니다.

alpha는 데이터에 가상의 양수 특성을 가진 데이터 포인트를 더하는 것처럼 작동합니다. 그 결과 특정 클래스에서 어떤 특성이 우연히 한 번도 나타나지 않았다고 해서 통계가 지나치게 극단적으로 굳어지는 것을 완화합니다. alpha가 크면 smoothing이 강해지고 모델은 덜 복잡해집니다. alpha가 작으면 실제 훈련 데이터의 카운트가 더 직접적으로 반영됩니다.

실제 학습 절차 전체를 재현한 것이 아니라, 교재의 “가상 데이터 포인트를 더해 통계를 smoothing한다”는 개념을 단순화한 시각화입니다.

강점

  • 학습과 예측이 매우 빠릅니다.
  • 훈련 절차를 이해하기 쉽습니다.
  • 고차원 sparse data에서 잘 작동합니다.
  • 큰 데이터셋에서 좋은 baseline이 됩니다.

약점

  • 효율성의 대가로 선형 분류기보다 일반화 성능이 조금 낮을 수 있습니다.
  • 낮은 차원의 복잡한 구조에서는 다른 모델이 더 나을 수 있습니다.
  • coef_가 선형 모델의 w와 같은 의미는 아니므로 해석에 주의해야 합니다.
