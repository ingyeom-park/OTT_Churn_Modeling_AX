# Legacy Segmentation Reference Pack

Purpose:
이 패키지는 park.ingyeom\_legacy(260512) 안의 v1/이전 corrected-chain 세그먼트 설계 구조를 참고하기 위한 것이다.

주의:
- legacy 수치, n, AUC, SHAP, segment별 재구매율을 현재 canonical 결과로 사용하면 안 된다.
- 현재 canonical 기준은 05b, 06, 09b, 10, 11b, 11b semantic patch, 12c이다.
- 이 패키지는 segment rule, multi-flag 구조, final_segment 우선순위 설계 방식 참고용이다.
- 현재 canonical 세그먼트는 아직 확정되지 않았다.
